#Juego-Manzanas

#Motor
Godot 4.5

#Como probarlo

1. Abrir el ejecutable de Godot 4.5
2. En la ventana de gestor de proyectos hacer clic en Importar
3. Seleccionar el archivo project.godot
4. Hacer clic en Importar y Editar
5. Una vez dentro del editor hacer clic en el botón de Play

#Controles

Izquierda: Flecha izquierda.
Derecha: Flecha derecha.

#Objetivo

Atrapar 50 manzanas para ganar.

#Qué revisar

1. Controles
2. Spawner de manzanas
3. Colisiones
4. Puntuación
5. Game Over
6. Reinicio
7. Paralax Layer
